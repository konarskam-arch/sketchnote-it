O co w tym chodzi?

JavaScript pozwala reagować na działania użytkownika. Zmienna przechowuje wartość, funkcja grupuje instrukcje, a zdarzenie uruchamia reakcję.

const powitanie = "Cześć!";
console.log(powitanie);
