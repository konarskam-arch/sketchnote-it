SQL od podstaw.

Zadawaj dobre pytania danym. Naucz się podstaw zapytań.

O co w tym chodzi?

SQL służy do pracy z relacyjnymi bazami danych. SELECT wybiera kolumny, FROM wskazuje tabelę, WHERE filtruje, a ORDER BY sortuje wyniki.

SELECT nazwa, cena
FROM produkty
WHERE cena < 100
ORDER BY cena;
